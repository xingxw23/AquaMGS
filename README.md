# AquaMGS

## Structure Guided Gaussian Splatting for Monocular Reconstruction of Deformable Aquatic Organisms

Official project page for **AquaMGS**.

This repository contains the public project-page source files for the AquaMGS paper, including:

- the homepage `index.html`
- style and script files under `static/`
- two fish demo videos used for webpage visualization
- four original method figures from the manuscript
